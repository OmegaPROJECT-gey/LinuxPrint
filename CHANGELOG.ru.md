## [Unreleased] — 2026-11-08

### Добавлено

- **Автоподгон фото** — новый модуль `services/fit.rs`: подбор формата бумаги
  по соотношению сторон снимка, `print-scaling fill` с расчётом обрезки в
  миллиметрах, альбомная ориентация, когда фото шире листа, и подпись итога
  (формат, ориентация, обрезка) под предпросмотром.

## [0.1.0] — 2026-10-20

Первый релиз.

### Добавлено

- **Печать**: выбор файлов и drag-and-drop (PDF и изображения напрямую; WebP
  собирается в PDF через image-энкодер; DOCX/ODT/RTF — через headless
  LibreOffice, если он установлен, иначе понятная подсказка), предпросмотр
  первой страницы PDF через `pdftoppm`, копии, диапазон страниц и списки
  формата/ориентации/полей/duplex/качества/кассеты/носителя из реальных
  опций принтера.
- **Собственный IPP-клиент** (`services/ipp.rs`, HTTP `application/ipp` к
  локальному cupsd): точные статусы заданий с откатом на `lpstat`, прогресс
  «лист X из Y» через `job-media-sheets`, операции Hold/Release/Restart-Job,
  ручное кодирование RFC 8010 и живой тест против запущенного CUPS.
- **Уведомления о завершении заданий** — опрос активных заданий каждые 3 с;
  при переходе в терминальное состояние отправляется системное уведомление
  (freedesktop Notifications, D-Bus через `gio::Notification`) и делается
  запись в журнал; счётчик активных заданий — метка в сайдбаре.
- **Отложенная печать** — «Сейчас / Днём / Вечером / Ночью / Выходные» через
  `job-hold-until`, именованные значения сверяются с реальными опциями
  принтера.
- **Экспорт журнала в CSV** (RFC 4180, открывается в LibreOffice/Excel),
  фильтр по категориям и текстовый экспорт; очистка журнала по-прежнему
  требует подтверждения.
- **gettext-переводы uk, de, fr** — собственный читатель/писатель PO/MO
  (`core/src/po.rs`), `make po` / `make po-build`, overlay-загрузка при
  старте с откатом на EN для пустых и fuzzy-записей; языки переключаются в
  настройках и поставляются внутри .deb/.rpm/Flatpak.
- **Пресет фото «4×6 / 10×15»** — фотопрофиль плюс размер листа; алиасы
  `4x6` / `10x15` / `100x150` подбираются по реальному списку медиа
  принтера, а если формата нет — приложение честно об этом сообщает и не
  делает вид, что настроило.
- **ICC-профили** — профили драйвера из PPD принтера (`*cupsICCProfile`,
  скачивается анонимным GET, поэтому работает и без группы `lp`), с пометкой,
  что CUPS применяет их автоматически и что ни CUPS, ни IPP не принимают
  произвольный ICC-файл.
- **Обнаружение в сети через DNS-SD** — сетевые Mopria-принтеры
  (`_ipp/_ipps._tcp`) и AirScan/eSCL-сканеры (`_uscan/_uscans._tcp`) через
  `avahi-browse -rtp` в параллельных потоках с дедупликацией, отдельной
  группой «Найдено в сети»; отсутствие Avahi даёт подсказку, а не ошибку.
- **Многостраничный TIFF** — собственный писатель (IFD-цепочка + Adobe
  Deflate, проверен через libtiff и Pillow), страницы WebP собираются в PDF
  перед отправкой задания в CUPS.
- **Собственный PDF-писатель** для сканов: Flate для растра, DCTDecode для
  JPEG, без перекодирования; многостраничный PDF с `{page}` в имени, когда
  формат не поддерживает несколько страниц.
- **Прогресс сканирования** постранично и в процентах (`scanimage --progress`
  читается потоком из stderr), отмена в любой момент, кадрирование в мм с
  клипом по границам устройства и поворот 0/90/180/270°.
- **OCR через Tesseract** с выбором языка (язык санитаризуется, результат —
  отдельный `.txt`).
- **Хранение и логи** — JSON в XDG-каталогах с атомарной записью, журнал с
  потолком 1000 записей, `tracing` в stderr и в файл с посуточной ротацией и
  настраиваемым уровнем.

### Безопасность

- внешние команды выполняются без shell, аргументы передаются вектором;
  `LC_ALL=C` для детерминированного разбора; жёсткие таймауты, kill и отмена
  пользователем; санитаризация имён файлов и языка OCR, пути ограничены через
  `naming::safe_join`; нигде не требуется root.
