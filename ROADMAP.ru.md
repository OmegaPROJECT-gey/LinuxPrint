## Сделано

- [x] **Собственный IPP-клиент** (`services/ipp.rs`) — HTTP `application/ipp`
      к локальному cupsd: точные статусы заданий (с откатом на `lpstat`),
      прогресс «лист X из Y» через `job-media-sheets`, операции
      Hold/Release/Restart-Job с подтверждением, ручное кодирование RFC 8010.
- [x] **Автообновление очереди каждые 3 с** с прекращением после неудач и
      кнопкой «Обновить».
- [x] **Уведомления о завершении заданий** — системные уведомления
      freedesktop через D-Bus (`gio::Notification`), запись в журнал и метка
      активных заданий в сайдбаре.
- [x] **Отложенная печать** — «Сейчас / Днём / Вечером / Ночью / Выходные»
      через `job-hold-until`, с проверкой имён по реальным опциям принтера.
- [x] **Экспорт журнала в CSV** (RFC 4180) и фильтр по категориям.
- [x] **Миграция i18n на gettext** — собственные инструменты PO/MO,
      `make po` / `make po-build`, полные переводы **uk, de, fr** поверх
      словаря RU/EN.
- [x] **Печать фотографий** — пресет «4×6 / 10×15» (алиасы сверяются с
      реальным списком медиа принтера), выпадающий список `print-scaling`
      (отправляется только если опция заявлена), **ICC-профили** из PPD с
      честной пометкой об автоматическом управлении цветом.
- [x] **Автоподгон фото, первая версия** — `services/fit.rs`: подбор формата
      бумаги по соотношению сторон, `print-scaling fill` с обрезкой в мм,
      альбомная ориентация, подпись итога под предпросмотром.
- [x] **Обнаружение через DNS-SD** — Mopria-принтеры и AirScan/eSCL-сканеры
      через `avahi-browse -rtp`, группой «Найдено в сети».
- [x] **Многостраничный TIFF** (собственный писатель, IFD-цепочка + Adobe
      Deflate) и **сборка WebP → PDF** перед отправкой в CUPS.
- [x] **Собственный многостраничный PDF-писатель** для сканов (Flate /
      DCTDecode, без перекодирования) и постраничный прогресс через
      `scanimage --progress`.

## Далее

- [ ] **Автоподгон фото до уровня Canon PRINT** — живое предпросмотр обрезки
      (что именно и на сколько будет отрезано) и автоматический выбор

- [ ] **Уровни чернил** — чтение IPP `marker-levels`, если принтер их
      отдаёт, и в противном случае честная отсылка к веб-админке устройства.
- [ ] **Прямая подписка на события cupsd** (D-Bus CUPS) вместо опроса очереди
      каждые 3 секунды: мгновенная смена состояния и никаких лишних запросов
      к остановленному демону.
- [ ] **% прогресса задания и «продолжить печать»** — реальный процент
      выполнения задания и возможность продолжить остановленное/приостановленное
      задание прямо из страницы очереди.
- [ ] **Распространение: Flathub, Copr, AUR** — наряду с уже существующими
      `.deb`/`.rpm` (nfpm) и Flatpak-бандлом из CI, чтобы установка была
      одной командой на каждом целевом дистрибутиве.
- [ ] **OCR-режим «текстовый PDF»** — сканирование сразу в PDF с текстовым
      слоем (изображение + слой Tesseract), а не в отдельный `.txt`.
- [ ] **AirScan-сканеры без `sane-airscan`** — прямой протокол eSCL, чтобы
      сетевые сканеры работали там, где пакета `sane-airscan` нет.
- [ ] **Машинное кадрирование в предпросмотре** (растяжение плана) — сейчас
      приложение намеренно использует точные поля в миллиметрах, это
      точнее и доступнее; умная подсказка была бы дополнением, а не заменой.

## Явно не планируется

* Проприетарные драйверы производителей и прошивки в комплекте — см.
  [PHILOSOPHY.ru.md](PHILOSOPHY.ru.md).
* Требование root, добавление принтеров через `lpadmin` внутри приложения и
  собственный демон.
* Телеметрия, аккаунты, реклама и любые сетевые вызовы, которые не делают
  CUPS, SANE, Avahi или принтер пользователя.

Когда пункт отсюда выполнен, он переезжает в [CHANGELOG.ru.md](CHANGELOG.ru.md)
и отмечается галочкой в том же pull request.
