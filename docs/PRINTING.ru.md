# Руководство по печати

[English](PRINTING.md) | **Русский**

Как LinuxPrinterG отправляет задания в CUPS, какие опции выставляет и что
делать, если что-то не работает. Общий обзор:
[../README.ru.md](../README.ru.md); поведение для фотографий:
[AUTO-FIT.ru.md](AUTO-FIT.ru.md).

## Как устроена печать

Стандартные пользовательские утилиты CUPS — без root и без `lpadmin`:

* **опции** — `lpoptions -p <принтер> -l` заполняет выпадающие списки
  реальными возможностями принтера (`PageSize`, `InputSlot`, `MediaType`,
  `Duplex`, `print-scaling` …), и каждое значение сверяется с ними до
  отправки: неподдерживаемый `media=…` отклоняется сообщением со списком
  доступных значений, а не неудачным `lp`;
* **отправка** — `lp -d <принтер> -n <копии> -o ключ=значение … -- <файл>`;
* **отмена** — `cancel <принтер>-<id>` (с подтверждением в интерфейсе);
* **очередь** — собственный IPP-клиент
  (`crates/linuxprinterg-core/src/services/ipp.rs`) шлёт HTTP
  `application/ipp` в локальный cupsd (`/run/cups/cups.sock` или
  `127.0.0.1:631`, учитывается `CUPS_SERVER`) и получает точные
  `job-state`; если IPP недоступен — откат на `lpstat -W … -o`.

## Принимаемые файлы

| Вход | Что происходит |
|---|---|
| PDF | отправляется как есть; предпросмотр — первая страница через `pdftoppm` (poppler-utils) |
| PNG / JPEG / TIFF / BMP / SVG / TXT / PS / EPS | отправляются как есть (CUPS-фильтры) |
| WebP | не все CUPS-фильтры его понимают → собирается в PDF собственным энкодером, печатается PDF |
| DOCX / ODT / RTF / PPT / XLS … | конвертация через LibreOffice headless (`soffice --headless`); без LibreOffice — подсказка установить или сохранить в PDF |
| всё остальное | отклоняется с просьбой сохранить документ в PDF |

## Параметры

| Строка в UI | Опция CUPS | Примечания |
|---|---|---|
| Копий | `-n`, плюс `Collate=true` при > 1 | 1–999 |
| Страницы | `page-ranges` | `1-3,7`; парсер в `domain/page_range.rs` |
| Формат бумаги | `media` | из `lpoptions -p … -l` |
| Кассета | `InputSlot` | |
| Тип носителя | `MediaType` | «Нет» = не отправляется |
| Подгонка под лист | `print-scaling` | отправляется **только** при заявленной принтером опции; индекс 0 = «По умолчанию (принтер)» (ничего не отправляется) |
| Двусторонняя | `sides` | отправляются только двухсторонние значения |
| Режим цвета | `print-color-mode` | цвет / оттенки серого / авто |
| Качество | `print-quality` | черновик / нормальное / высокое / фото |
| Ориентация | `orientation-requested` | книжная / альбомная (+ реверсивные) |
| Печатать | `job-hold-until` | отложенная печать, см. ниже |

**Фотопрофиль** включает качество «Фото», цвет, одностороннюю печать и тип
носителя «фото», если принтер его сообщает. **Фото 4×6 / 10×15** делает то же
самое и дополнительно подбирает размер листа по псевдонимам
`4x6`/`10x15`/`100x150` (точное совпадение → безполейный → вхождение); если
такого медиа у принтера нет — честное сообщение, размер не меняется.

## Отложенная печать

Строка «Печатать» (`job-hold-until`): **Сейчас** (ничего не отправляется) /
**Днём** / **Вечером** / **Ночью** / **Выходные** → значения CUPS `day-time`,
`evening`, `night`, `weekend`. Именованные значения сверяются с реальными
`job-hold-until` принтера; ручное время `HH:ММ` передаётся без проверки.

## Очередь

* точные IPP-статусы: «В обработке» (с «стр. X из Y» из
  `job-media-sheets-completed`/`job-media-sheets`, когда принтер их
  сообщает), «Приостановлено», «Остановлено», «Выполнено», «Отменено»,
  «Прервано»; ожидающие задания показываются без подписи статуса;
* действия: отмена (с подтверждением), **Приостановить / Продолжить** для
  активных заданий и **Перезапустить** для завершённых — IPP-операции над
  заданием с подтверждением и записью в журнал;
* автообновление каждые **3 сек**; после **двух неудач подряд** опрос
  останавливается до ручного «Обновить» (или успешного опроса);
* завершение наблюдаемого задания → системное уведомление (freedesktop
  Notifications через D-Bus) и запись в журнал; число активных заданий —
  значок рядом с «Печать»;
* в списке активные задания и **последние 10 выполненных**; на откате через
  `lpstat` различаются только «активное/выполнено».

## Устранение неполадок

### Очередь ничего не принимает (принтер на паузе)

```bash
lpstat -p             # «disabled» — очередь на паузе
cupsaccept MyPrinter  # снова принимать задания
cupsenable MyPrinter  # и включить очередь
```

### CUPS не запущен

Приложение показывает баннер «Служба CUPS не запущена»:

```bash
sudo systemctl status cups
sudo systemctl start cups
lpstat -r             # должен ответить "scheduler is running"
```

### Задание ушло в error-состояние

```bash
lpstat -W all -o        # все задания, включая неудачные
lpstat -o               # незавершённые задания
sudo tail -n 100 /var/log/cups/error_log
```

Пропишите `LogLevel debug` в `/etc/cups/cupsd.conf` и перезапустите cupsd —
причина (нет драйвера, устройство офлайн, сбой фильтра) попадёт туда.
Собственный лог приложения:
`~/.local/state/linuxprinterg/logs/linuxprinterg.log` (ротация раз в сутки).

### Принтер не найден

```bash
lpstat -v                    # URI, которые знает CUPS
avahi-browse -rtp _ipp._tcp  # сетевые (Mopria) принтеры
```

Сетевые принтеры обычно добавляются как `ipp://host:631/printers/NAME` или
`ipps://host/ipp/print` (driverless IPP Everywhere) через
`system-config-printer` или `http://localhost:631/admin` — оба сами
запрашивают polkit; приложение никогда не вызывает `lpadmin`.

### Поля и обрезка

* лист должен совпадать с тем, что заявляет драйвер:
  `lpoptions -p MyPrinter -l | grep -i pagesize`;
* широкие белые поля — классический случай «фото на A4» → включите
  **Автоподгон фото** ([AUTO-FIT.ru.md](AUTO-FIT.ru.md));
* поля печати — это драйверские CUPS-опции; их список зависит от принтера
  и приложение его не выдумывает.

### У принтера нет драйвера

CUPS использует драйверы, установленные в системе; LinuxPrinterG своих не
поставляет:

```bash
# Debian/Ubuntu
sudo apt install cups-filters printer-driver-gutenprint hplip
# Fedora
sudo dnf install cups-filters gutenprint hplip
# Arch
sudo pacman -S cups-filters gutenprint hplip
```

Современные принтеры чаще работают **без драйвера** (IPP Everywhere /
Mopria) и вообще не нуждаются в вендорных драйверах; общие фильтры даёт
`cups-filters`.

## Полезные команды от руки

```bash
lpstat -t                  # всё сразу
lpoptions -p MyPrinter -l  # поддерживаемые опции и значения
lp -d MyPrinter -o media=A4 -o print-scaling=fill photo.jpg
cancel MyPrinter-23        # отмена по токену задания
cupsdisable MyPrinter      # поставить печать на паузу
```
