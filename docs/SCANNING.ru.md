# Сканирование

[English](SCANNING.md) | **Русский**

Как LinuxPrinterG сканирует через SANE, что можно изменить и куда попадают
файлы. Обзор: [../README.ru.md](../README.ru.md); печать:
[PRINTING.ru.md](PRINTING.ru.md).

## Как устроено сканирование

Всё через системную утилиту SANE `scanimage` — приложение своих сканерных
драйверов не содержит (`crates/linuxprinterg-core/src/services/sane.rs`):

* `scanimage -L` — список устройств;
* `scanimage --help -d <id>` — разрешения, режимы, источники, границы
  устройства;
* `scanimage --device-name=… --resolution=… --mode=… --source=…
  --format=pnm --progress` — один запуск на страницу, вывод разбирает
  собственный читатель PNM.

Запуски идут в фоновых потоках с жёсткими таймаутами и `CancelHandle`,
который убивает `scanimage` по кнопке «Отменить сканирование».

## Бэкенды и источники

* USB-сканеры работают через любой бэкенд, установленный в системе;
* сетевые и **AirScan/eSCL**-сканеры требуют бэкенд `escl` — тогда они
  видны в `scanimage -L` как `escl:https://…` (пакет `sane-airscan`);
* источники берутся из `scanimage --help`: **Flatbed**, **ADF**,
  **ADF Duplex** (только если сканер их заявляет). Flatbed всегда
  сканирует **один лист за проход** — кладёте лист и нажимаете снова;
  автоматическая подача — задача ADF;
* «Страниц (0 = все из ADF)»: `0` читает, пока податчик не сообщит, что листов
  нет (с предохранителем в 200 страниц от зацикливания); пустой податчик
  после первой страницы завершает скан нормально, а если страниц нет вообще —
  сообщение «Нет страниц: в податчике документов нет листов».

## Разрешение, режим, прогресс

* список разрешений парсится из `scanimage --help` (запасной вариант
  `75 100 150 200 300 600 1200`); запрос зажимается в 50–4800 dpi,
  сохраняемое значение — в 50–2400;
* режимы Lineart / Grayscale / Color — тоже из `--help`;
* прогресс показывается **постранично и в процентах** — `scanimage --progress`
  пишет `Progress: 45.3%` в stderr, а приложение читает поток на лету.

## Кадрирование и поворот

* «Область кадрирования, мм»: X / Y / Ширина / Высота в миллиметрах,
  передаются в `scanimage` как `-l/-t/-w/-h` и обрезаются по границам
  устройства из `--help`; «Весь лист» сбрасывает поля;
* поворот 0° / 90° / 180° / 270° применяется к каждой странице.

## Сохранение

| Формат | Как |
|---|---|
| **PDF** | собственный писатель (`services/pdf.rs`): один файл на весь скан, растровые страницы сжимаются zlib (`FlateDecode`), JPEG-страницы встраиваются без перекодирования (`DCTDecode`); проверяется `pdftoppm` |
| **TIFF** | собственный многостраничный писатель (`services/tiff.rs`, цепочка IFD + Adobe Deflate), один файл на весь скан; проверяется libtiff и Pillow |
| PNG / JPEG / WebP | по одному файлу на страницу (кодеки не умеют многостраничность) |

Если страниц несколько, а в шаблоне нет `{page}`, приложение дописывает
`_{page}` само. Каталог по умолчанию: `~/Documents/Scans` (меняется на
странице сканирования и в настройках).

### Шаблон имени файла

Поля: `{base}` (имя исходного файла), `{device}`, `{date}`, `{time}`,
`{page}`, `{n}`, `{ext}` — по умолчанию `{date}_{time}_{base}`. Результат
очищается (разделители путей и управляющие символы → `_`) и делается
уникальным (`(2)`, `(3)` …), а выйти за выбранный каталог он не может
(`naming::safe_join`).

## OCR (опционально)

Тумблер рядом с форматом: Tesseract пишет `.txt` рядом со сканом. Языки в
списке: `rus+eng`, `rus`, `eng` (строка очищается перед вызовом tesseract,
`--psm 1`, таймаут 300 с). Языковые данные — отдельный пакет: Debian/Ubuntu
`tesseract-ocr-rus`, Fedora `tesseract-langpack-rus`, Arch
`tesseract-data-rus`.

## Устранение неполадок

### Сканер не виден

```bash
scanimage -L              # что видит SANE
sane-find-scanner         # определение USB без бэкенда
scanimage --help -d <id>  # отвечает ли устройство?
```

### Нет бэкенда escl (сетевой / AirScan-сканер)

```bash
# Debian/Ubuntu, Fedora, Arch
sudo apt install sane-airscan     # или dnf / pacman с тем же именем
```

После этого проверьте `scanimage -L` снова — устройство должно появиться как
`escl:https://…`.

### Права на USB

Если `scanimage -L` работает только под root, добавьте пользователя в группу
`sane` (и убедитесь, что сканер не занят другим процессом — приложение
сообщает «Сканер занят»). Приложение никогда не запускается от root.

### Сетевой сканер и обнаружение

```bash
avahi-browse -rtp _uscan._tcp   # AirScan/eSCL-сканеры в локальной сети
```

Страница «Устройства» показывает их в группе «Найдено в сети» дополнительно к
списку SANE; без установленного Avahi вместо ошибки даётся подсказка.

## Полезные команды от руки

```bash
scanimage --device-name=escl:https://192.168.1.5:443 \
  --resolution 300 --mode Color --source Flatbed --format=pnm > out.pnm
tesseract out.pnm stdout -l rus+eng --psm 1  # OCR страницы
```
